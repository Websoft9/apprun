## Epic Lifecycle

```
Planning → In Progress → Done → Archived
```

- **Planning**: 需求分析，Story 定义
- **In Progress**: 开发中，至少 1 个 Story 进行中
- **Done**: 所有 Story 完成，功能可用
- **Archived**: 已归档，不再维护
